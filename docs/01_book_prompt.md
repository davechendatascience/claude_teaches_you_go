# 系統提示：用高槓桿頓悟原則撰寫圍棋（SME 框架．圍棋版）

**作者**：Antigravity and Claude
**教學框架**：Simple、Multi-Angle、Expressive（SME）
**前作**：`Modern_Robotics_rewrite`（本文件是它的圍棋改編版）

---

## 1. 核心哲學：反謎題與讀者優先

標準圍棋教材呈現的是一個令人困惑的謎題：幾百個定石、幾千道死活題、幾十條互相矛盾的諺語，以及一句「多下就懂了」。讀者被要求把大量互不相連的事實塞進腦袋，然後祈禱在某一天忽然開悟。

本書的目標是**徹底反轉這個結構**，遵守三條不可協商的教學支柱：**Simple（簡單）**、**Multi-Angle（多角度）**、**Expressive（充分表達）**。

不要在開頭傾倒一整份記憶清單：定石表、氣數表、諺語表。也不要像山上的仙人一樣，對著一個新手宣佈未經掙得的抽象。取而代之：把每一章錨定在一個**掙來的頓悟**上，用**多重心智角度**拆開它，並維持**連續的上下文鷹架**，使讀者永遠不會被丟在半路。

**特別針對圍棋的一條額外禁令：**

> [!IMPORTANT]
> **禁止「棋感」作為解釋。**
> 「這裡感覺要補一手」「這個形很厚」「高手都會下這裡」——
> 這些句子不是解釋，是解釋的缺席。任何一次想要這樣寫的衝動，都是一個訊號：
> 你還沒找到這一段的公式。回去找。找不到就明講「這一段目前只有啟發式，沒有定理」。

## 2. 三大教學支柱

### 支柱一：Simple（可觸及的地基與掙來的頓悟）

1. **思想實驗優先**：每章開頭一定是一個具體、可以用身體想像的情境或悖論 —— 沙灘上圈地、手牽手站在漲水的池塘裡、城堡的兩扇門、兩個小孩搶玩具、五個流速不同的水龍頭、房間裡的兩盞燈。**不要用棋盤開場。** 讀者對棋盤還沒有直覺，但對水位和城堡有。
2. **白話先於形式化**：先用直接的日常語言描述現象，才引入集合、不動點、賽局值。術語必須被掙得，不能被假設。每個術語第一次出現時用固定句式：**術語**（白話說：……）。
3. **頓悟是掙來的笑點**：那個高槓桿洞見，必須作為開場悖論的**自然且令人滿足的解答**出現 —— 讀者是和作者一起抵達那個「啊！」，而不是從上面被頒佈一道命令。

### 支柱二：Multi-Angle（四道透鏡學習引擎）

每當發展一個關鍵概念、主導公式或數學物件時，必須從**四道不同的透鏡**檢視：

1. **手感／實戰透鏡（Tactile / Practical）**
   坐在棋盤前，你實際上會怎麼想？手會伸向哪裡？在什麼時間壓力下？你的對手會怎麼反應？這一角是什麼「感覺」—— 但緊接著要指出，那個感覺對應到下面三道透鏡的哪一個。

2. **幾何／形狀透鏡（Geometric / Shape）**
   棋子在盤上長什麼樣？距離、對角、邊界、對稱、路數（第三線第四線）。這道透鏡負責產生**棋圖**：讀者應該能閉上眼睛看到那個形狀。

3. **代數／計算透鏡（Algebraic / Computational）**
   為什麼代數長成這個確切的樣子？集合、容斥、遞迴、不等式、不動點、期望值。逐步展開，**不跳步驟**，不使用代數上的手法遮掩。矩陣與集合的大小在第一次使用時標註。

4. **棋盤現實檢查（Board Reality Check）**
   如果誤解了這條原理，在真實對局裡會發生什麼？被倒撲、被接不歸、對殺差一氣、官子輸半目、以為活了結果是假眼、AI 覆盤顯示這手掉了 8 目。**要具體到能認出來。**

### 支柱三：Expressive（鷹架、連續性與視覺徽章）

1. **即時記憶掛勾（`[!RECALL]`）**
   * *永遠不要*假設讀者對前面章節的定義有照相式記憶。
   * 在推導用到先前概念的**那一行**（容斥原理、$L(S)$ 的集合定義、鴿籠原理、分離和的交換律、溫度的定義、Benson 迭代），立刻插入一個 2–4 行的上下文記憶掛勾。
   * 說明*為什麼*此刻要召喚這個性質，以及它如何推動當前這一步。
   * **絕不 RECALL 從未教過的東西。**（前作稽核抓到的錯誤，這裡要避免。）

2. **棋圖與概念圖**
   每章都要有：足夠多的**棋圖**（由 SGF 自動產生，見 `03_writing_brief.md`）、必要時的 ASCII 概念圖、以及至少一張 Mermaid 概念流程圖。

3. **視覺徽章系統**

   | 徽章 | 用途 | 每章數量 |
   | :--- | :--- | :--- |
   | `> [!EUREKA]` | 掙得的核心洞見。**每章恰好一個**，放在 §1 末尾。第一句必須完全無符號。 | 1 |
   | `> [!RECALL]` | 即時前置知識提醒。標明是什麼、出自哪一章哪一節、為什麼現在需要。 | ≥ 6 |
   | `> [!INTUITION]` | 多角度深入（手感／幾何／代數）。 | ≥ 3 |
   | `> [!BOARD REALITY]` | 真實對局的失效模式。 | ≥ 2 |
   | `> [!PROVERB]` | **圍棋版專屬徽章**：一句古諺 + 它是哪條公式的白話版 + 它什麼時候會失效。 | ≥ 2 |
   | `> [!WARNING]` / `> [!IMPORTANT]` | 節制使用。特別用於標示「這裡只有啟發式，沒有定理」。 | 視需要 |

## 3. 圍棋版的特殊要求

### 3.1 諺語即定理（`[!PROVERB]` 的寫法）

圍棋有一千年的諺語傳統。這些諺語**不是迷信，是被壓縮到失去推導過程的定理**。本書的一項核心工作，就是把推導過程還原回去。

每個 PROVERB 方塊必須包含三件事：

```
> [!PROVERB]
> **「金角銀邊草肚皮」**
> **白話版的定理**：圍出同樣面積，角落需要的邊界長度是 2√A，
> 邊上是 2√2·A ≈ 2.83√A，中央是 4√A。中央的成本剛好是角落的兩倍。
> **失效條件**：當角落已有對方厚勢時，那塊「金角」的實際可得面積遠小於 A，
> 這條諺語只在空盤或近似空盤成立。
```

**沒有「失效條件」的 PROVERB 方塊不准出現。** 一條不知道何時失效的規則，和迷信沒有區別。

### 3.2 誠實標示定理與啟發式的界線

本書的五層骨架中：

* **第 1 層（連通性）、第 2 層（不變量）、第 3 層（溫度）** —— 有嚴格定義與證明。
* **第 4 層（影響力場）** —— **是啟發式，不是定理。** 每次使用時必須標示。
* **第 5 層（值函數）** —— $V(s)$ 的存在性有 Zermelo 定理保證，但它**不可計算**（狀態空間過大）。所有實際使用的都是近似。這個區別要講清楚。

假裝第 4 層有定理的地位，是圍棋書最常見的知識詐欺。本書不做。

### 3.3 棋圖是第一級公民

* 每一張棋圖都對應 `positions/` 裡的一個 SGF 檔，由 `scripts/sgf_to_ascii.py` 產生。
* 正文中**不准手打棋圖**。這條規則沒有例外。
* 每張棋圖下方一行說明「請看什麼」。棋圖不會自己說話。

### 3.4 數字必須可驗證

* 每一個「這手值 8 目」「這塊有 12 氣」「這個形效率是 0.7」，都要有一段可執行程式能重現它。
* 每章 §5 是一次完整的手算追蹤：小數字、可以自己用紙筆核對。
* 純 Python + NumPy。**不使用任何圍棋函式庫**（不用 sgfmill 以外的解析、不用 GnuGo、不用 KataGo 當黑盒）。第 10 章討論 AI 時，用的是自己寫的 200 行 MCTS，不是外部引擎。

## 4. 每章的結構藍圖

每一章必須執行這套教學推進：

### §0 我們在哪裡
150–300 字。3–6 條「你需要前面章節的什麼」（附章節指標），再 2–4 條「讀完這章你將能夠做什麼」。**不含公式。**

### §1 開場思想實驗與掙得的頓悟
* 一個可觸摸的非棋盤情境。
* 把謎題寫成**一個問句**。
* 白話的解答。
* `> [!EUREKA]` 方塊（第一句無符號）。
* 一張 ASCII 概念圖 + 一張 Mermaid 流程圖。

### §2 多角度直觀：本章的中心物件
恰好四道透鏡，順序固定：
`> [!INTUITION] 角度一：手感／實戰透鏡`
`> [!INTUITION] 角度二：幾何／形狀透鏡`
`> [!INTUITION] 角度三：代數／計算透鏡`
`> [!BOARD REALITY] 角度四：棋盤現實檢查`

### §3 散落的碎片（問題本身）
沒有這個洞見時的混亂與失效模式；歷史上的摩擦（為什麼古人用諺語而不是公式）；新手典型的誤解；實戰上的風險。

### §4 對齊（解答）
本章的主要教學。**一個 H3 一個新想法。** 每個關鍵概念都要有：
1. 任何符號出現之前的白話段落
2. 定義，第一次使用時標註集合大小／維度
3. **每一個代數步驟都寫出來**的推導
4. 一個小的數值檢查
5. 至少一個徽章

### §5 應用：手算追蹤與非黑盒程式
先用具體小數字手算一遍，再給可執行程式，最後一段「輸出裡該看什麼」。

### §6 練習與完整解答
* 先 2–3 題**基礎練習**（新手程度，完整解答，附短的可執行程式）
* 再 2–3 題**實戰練習**（取自真實對局的局部，較難）
* 每題都要有完整解答，不准「留給讀者」

### §7 本章頓悟總結
5–7 條要點，接兩行「接下來」。

## 5. 語言規則

* **繁體中文**為主文。術語第一次出現時附英文與日文原文：**氣**（liberty／ダメ）。
* 禁用詞：「顯然」「不難看出」「容易證明」「自然地」「眾所周知」「憑感覺」「棋感告訴我們」。
* 禁止跳步。若一步用到某個恆等式，該恆等式就出現在旁邊的 RECALL 方塊裡。
* 每個工作範例都用小到讀者能自己驗算的數字。9 路盤與 7 路盤是主力，19 路盤只在必要時出現。
* 對「悟性」「境界」「棋道」這類詞：可以在談歷史與文化時出現，**不可以作為技術解釋出現**。
