# 公式索引：從概念到公式

這一頁是全書的**公式總表**。每一列回答同一個問題：**這個圍棋概念，寫成數學是什麼樣子？**

它有三個用途：

1. **寫作時的契約** —— 每一章都必須把它負責的那幾列真正推導出來。沒有推導的列不准出現在這裡。
2. **讀者的速查表** —— 讀完全書後，這一頁是唯一需要留在手邊的東西。
3. **誠實的界線** —— 標記 🟡 的列是**啟發式**，不是定理。標記 🔴 的列是**待驗證**，作者尚未完成推導，不准寫進正文。

| 標記 | 意思 |
| :--- | :--- |
| 🟢 | 有完整證明，且有可執行程式驗證 |
| 🟡 | 啟發式／經驗模型，**沒有證明**，正文必須明講 |
| 🔴 | 待完成：推導或驗證尚未做完 |
