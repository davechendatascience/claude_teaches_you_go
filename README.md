## 給審閱者：這本書的證據標準

這本書的核心主張是**「圍棋的口訣是定理的白話版」**。這個主張只有在能區分
「證明了什麼」與「只是量到什麼」時才有意義，所以全書用三個標記：

| 標記 | 意思 | 例子 |
| :--- | :--- | :--- |
| 🟢 | **有證明**，而且有可執行程式驗證 | 兩眼定理、Benson、對殺判定式、溫度 |
| 🟡 | **啟發式或經驗量測**，沒有證明；正文必須明講 | 整個第 9 章（影響力場）、第 11 章的規則評分 |
| 🔴 | **待完成**：推導或驗證尚未做完，**不准寫進正文** | 目前僅剩數子／數目等價定理相關兩列 |

完整對照表在 [`docs/04_formula_index.md`](docs/04_formula_index.md)。

### 三件審閱時值得特別檢查的事

**一、標 🟡 的東西有沒有被當成 🟢 用。** 第 9 章整層是啟發式，該章開頭有 WARNING
明確說明；第 11 章的量測全部來自 **3 路盤**，該章 §4.4 與 §4.5 各有一個
BOARD REALITY 說明哪些可以外推、哪些不行。

**二、小盤面的結論有沒有被當成 19 路的結論。** 第 10、11 章的精確計算只在
3 路盤上做得到（4 路盤已經算不完）。書中凡是引用這些數字的地方，都應該
同時說出它的適用範圍。**如果有任何一處沒說，那是錯誤，請指出來。**

**三、被程式推翻的宣稱有沒有留下來。** 本書的方法是「先寫下宣稱，再寫程式反駁它」。
寫作過程中有三個我原本以為對的說法被自己的程式打死，它們**連同推翻它們的程式**
一起留在書裡：

* 第 8 章 §4.1：「虎比實接多兩口氣」—— 實測 8、8、8，完全一樣。
* 第 9 章 §4.2：「Bouzy 的膨脹／侵蝕比較貼近人類直覺，所以比較準」—— 相同覆蓋率下和一行指數衰減一樣。
* 第 2 章 §4.5：「長方形是最省的圍地形狀」—— 面積 5 時菱形要 8 顆、長方形要 12 顆。

## 每一張圖、每一段程式都是生成的

書上**不准手打任何一張棋圖或圖表**。四個檢查器把這條規矩變成 CI：

```bash
python scripts/check_diagrams.py      chapters/*.md   # 棋圖 vs positions/*.sgf，逐位元組
python scripts/check_figures.py       chapters/*.md   # 場圖／表格 vs figures/*.txt
python scripts/check_chapter_code.py  chapters/*.md   # 每個 python 區塊都要能跑、要有 print 與 assert
python scripts/check_prose.py         chapters/*.md   # H2 結構、字數、徽章下限、諺語失效條件、禁用詞
python -m pytest tests/ -q                            # 計算核心
```

四個檢查器與全部測試目前皆通過。

## 一句話

圍棋的每一條口訣都是一個定理的白話版，而它們全部來自同一組五個概念：
**連通性、不變量、溫度、場、值函數** —— 外加一個例外：**劫**。

而第 10 章的結論是：那五層不是五個工具箱，是**同一個值函數 $V$ 的五種便宜近似**。
